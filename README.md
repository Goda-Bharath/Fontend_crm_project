Frontend CRM Project

This project is a Frontend Customer Relationship Management (CRM) application that I built during my internship. It focuses on managing customer data, campaigns, and interactions through a clean and user-friendly interface.

The main goal of this project was to understand how real-world CRM systems work and how frontend applications interact with data to provide meaningful insights.

About the Project

During my internship, I worked on building a CRM dashboard that allows users to manage leads, campaigns, trainers, and customer details. The application is designed to be responsive and easy to use, with a focus on modern UI and smooth user experience.

This project helped me improve my skills in React, component structuring, and frontend logic building.

 Features
 
 Dashboard with basic overview
 Manage campaigns and track details
 View and manage customer information
 Trainers and learners management
 Search and filter functionality
 Interactive UI components
 Responsive design for different devices

Technologies Used

 React (Vite)
 Tailwind CSS
 React Router
 JavaScript / TypeScript
 HTML and CSS
